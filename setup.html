Setup guide

You need a SQL Server to run the queries and two databases to run them on. The course is recorded on SQL Server, and every query in the lessons runs as shown there.

Pick your path

PathForCost
SQL Server Express + SSMSWindows (same screens as the videos)Free
Docker + VS CodeMac (same SQL, different editor)Free
Parallels with WindowsMac, SSMS exactly like the videos (needs about 16 GB RAM)About 100 dollars a year, 14-day trial

Windows

  1. Install SQL Server Express, choose Basic. Note the server name shown at the end: localhost\SQLEXPRESS.
  2. Install SQL Server Management Studio (SSMS) with defaults.
  3. Open SSMS, skip the sign in, enter the server name, choose Windows Authentication, tick Trust Server Certificate, Connect.

Mac (Docker)

  1. Install Docker Desktop (Apple chip). In its settings choose the Apple Virtualization framework and turn on Rosetta for x86_64 emulation, because SQL Server ships for Intel chips.
  2. Install Visual Studio Code and the SQL Server (mssql) extension.
  3. In the course files open 00_setup/mac-docker and double click start.command. It starts SQL Server and creates both databases.
  4. In VS Code add a connection: server localhost, port 1433, trust the certificate, SQL Login user sa, with the password from the course setup guide.

By hand instead of the script:

docker run -e "ACCEPT_EULA=Y" -e "MSSQL_SA_PASSWORD=YourStrong!Passw0rd" \
  -p 1433:1433 --name sql --platform linux/amd64 \
  -d mcr.microsoft.com/mssql/server:2022-latest

Passwords need 8+ characters with upper case, lower case, a number and a symbol.

Create the databases (three ways)

  1. Run the scripts (easiest). Open 01_datasets/00_sql-server/init-sqlserver-mydatabase.sql in SSMS and execute, then do the same for init-sqlserver-salesdb.sql with the toolbar database set to master. Use only the files in 00_sql-server.
  2. Restore the .bak files. Copy them into your server's Backup folder first (SQL Server cannot read Downloads), then Restore Database > Device. Backups are from SQL Server 2022, so they restore on 2022 or newer only.
  3. Import CSVs. Works as a demo, but CSV cannot tell empty text from NULL, which the NULL lessons need.

Which database for which chapter

MyDatabase: SELECT, DDL, DML, Filtering, Joins (first part), String functions, Aggregate functions. SalesDB: everything else, from Set operators to AI and SQL. Each script starts with a USE line naming the database it needs.

Extra: AdventureWorks

The index chapter uses Microsoft's free AdventureWorksDW2022 sample (table FactInternetSales). Download the .bak from Microsoft Learn and restore it like the course backups.

When something breaks

What you seeFix
Error 26, cannot locate serverStart the "SQL Server (SQLEXPRESS)" service. Developer edition uses just localhost.
Certificate chain not trustedTick Trust Server Certificate.
Msg 262 CREATE DATABASE permission deniedLog in with the Windows account that installed SQL Server, or get added to sysadmin.
Msg 911 or backtick syntax errorsYou ran a MySQL or Postgres script in SSMS. Use 00_sql-server.
Restore cannot see .bak / Access deniedCopy the file into the server's Backup folder.
Msg 3169 backup incompatibleServer older than 2022. Run the scripts or install 2022/2025 Express.
DATETRUNC not recognizedNeeds SQL Server 2022 or newer.
Cannot connect to Docker daemonStart Docker Desktop and wait for the whale icon.
no matching manifest for linux/arm64Enable Rosetta, or add --platform linux/amd64.
Port already allocatedAnother server uses 1433. Stop it or map to 1434.
Container stops right awayPassword does not meet the rules.
