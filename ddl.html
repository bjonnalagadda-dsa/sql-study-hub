2. Define Structure: DDL

Database: MyDatabaseScript: 02_Data_Definition_DDL.sql

DDL (Data Definition Language) shapes the database itself: CREATE builds a table, ALTER changes it, DROP removes it.

Remember this

  • CREATE builds, ALTER modifies, DROP destroys.
  • DDL changes the container; DML changes the contents.

Command families

SQL commands fall into groups: DQL (SELECT, reads data), DDL (CREATE, ALTER, DROP, changes structure) and DML (INSERT, UPDATE, DELETE, changes data).

CREATE TABLE

Name the table, then list each column with a data type and optional constraints. NOT NULL means a value is required. A PRIMARY KEY uniquely identifies each row.

CREATE TABLE persons (
    id INT NOT NULL,
    person_name VARCHAR(50) NOT NULL,
    birth_date DATE,
    phone VARCHAR(15) NOT NULL,
    CONSTRAINT pk_persons PRIMARY KEY (id)
)

ALTER TABLE

Add or remove columns on an existing table without recreating it.

ALTER TABLE persons ADD email VARCHAR(50) NOT NULL
ALTER TABLE persons DROP COLUMN phone

DROP TABLE

Deletes the table and all its data. There is no undo, so be sure.

DROP TABLE persons

Common mistakes

  • Adding a NOT NULL column to a table that already has rows and giving no default value.
  • Confusing DROP TABLE (table gone) with DELETE (rows gone, table stays).

Check yourself

What are the three DDL commands in this course?

CREATE, ALTER, DROP.

Difference between DDL and DML?

DDL defines structure (tables, columns). DML changes the data inside the tables.
