About the course

What the course is and why it's worth following.

SQL as the foundation

SQL is the language data professionals use to query data, spot patterns, and build insights. It underpins work in Power BI, Tableau, and Python.

Understand, don't memorize

The goal is to understand how data moves and connects between tables, not just to memorize commands.

Your mentor

Setup

Two free tools from Microsoft are all you need to follow along.

  1. Install SQL Server Express. This hosts your database. Download
  2. Install SQL Server Management Studio (SSMS). This is where you write and run queries. Download
  3. Download the course files. Datasets, scripts, and resources for the course and its three projects. Free download
  4. Optional: install a sample database. Microsoft's AdventureWorks guide walks you through it. Guide
